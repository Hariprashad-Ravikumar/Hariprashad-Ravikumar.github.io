## Projects

During my internship at Western Digital, I delivered two HAMR projects of equal scope: an analytical physics model for multi-write erasure, and a full-stack enterprise simulation app that lets engineers calculate the signal-to-noise ratio of recording media using physics and statistical models.

## 1. Physics Modeling

The team needed to understand write behavior across multiple write cycles to reduce adjacent track erasure (ATI and xTI) in high-density storage, avoiding the cost and latency of purely hardware-based experiments.

I derived a closed-form analytical model of grain magnetization dynamics from first principles to connect recording media properties to write behavior. Building on Néel-Arrhenius thermal switching and the Stoner-Wohlfarth model, I formulated expressions for switching time, noise power, and the probability of switching across multiple write cycles. I validated the model against Monte Carlo stochastic simulations and experimental spin-stand data on highly complex magnetic grain ensembles.

**Result:**
* Engineers can now predict and reduce erasure computationally.
* We are preparing the core models and research findings for a peer-reviewed publication.

## 2. Physics Simulation App

The engineering team needed a way to evaluate recording performance and signal-to-noise ratios directly from material parameters.

I built and deployed a full-stack enterprise physics simulator using Dash. A modular Python physics and statistical library backs the frontend, calculating these metrics in parallel.

Engineers use the tool to run real-time parameter sweeps, compare simulation runs side by side, and export results automatically as PowerPoint or Excel reports. We packaged the app as a PyPI-installable Python library with a clean API, integrating it into a broader internal platform alongside other Dash and Plotly tools.

The application accelerates development cycles by removing a hardware-experiment step from the loop, reducing overall testing costs.

## Hackathon

At the WD Intern Summit 2026 Hackathon in San Jose, our team won the "Wildest Idea" award. We built a fully working, scalable 3D browser-based game from scratch in just a few hours.

**WD Aquarius** is a first-person robotic shark exploration game that runs entirely in the browser. We built it using:
- **Three.js / WebGL** for real-time 3D rendering
- **Simplex Noise** for procedural terrain and ocean generation
- **Pointer Lock API** for physics-based first-person swim controls with velocity and drag simulation
- **Web Audio API** for an immersive underwater soundscape
- **HTML / CSS / JavaScript / TypeScript** for a custom sci-fi HUD featuring live telemetry, sonar, and depth tracking
- **Vite** for bundling and the local development server

We chose not to use engines like Unity or Unreal, proving that the ambitious scope was possible with native web technologies.
